## Prerequisites

- **Docker** — Docker Engine 24+ with Docker Compose v2
- **Node.js** — 18.x or later (for the CLI)
- At least one AI provider API key (for example OpenAI, Anthropic, or DeepSeek)

## Install the CLI

Yonaris currently retains the upstream npm package and executable names for deployment compatibility:

```bash
npm install -g @elmohq/cli
```

## Initialize Your Instance

Run the interactive setup wizard:

```bash
elmo init
```

The wizard walks you through:

1. **Config directory** — Where to store your `elmo.yaml` and `.env` files (default: `~/.elmo`)
2. **PostgreSQL** — Run Postgres in Docker (recommended) or provide an existing `DATABASE_URL`
3. **AI Providers** — Configure scrapers (BrightData, Oxylabs, Olostep, DataForSEO) and/or direct model APIs (OpenAI, Anthropic, DeepSeek, Mistral, OpenRouter); see [Providers](/docs/user-guide/providers) for details
4. **Start** — Optionally start the stack immediately

Once complete, the Yonaris setup generates two files in your config directory:

| File | Purpose |
|------|---------|
| `elmo.yaml` | Docker Compose configuration for all services |
| `.env` | Environment variables, secrets, and API keys |

## Start Yonaris

If you didn't start during init, bring everything up with:

```bash
elmo compose up -d
```

This pulls the Docker images and starts all services. Once they report healthy, open **http://localhost:1515** in your browser.

## System Architecture

| Service | Role |
|---------|------|
| **Web** | Dashboard UI and REST API |
| **Worker** | Background scheduler that drives prompt runs |
| **Postgres** | Shared database and job queue |
| **LLM APIs** | Direct API calls (OpenAI, Anthropic, DeepSeek, Mistral, OpenRouter) |
| **LLM Scraper** | Scrapers for ChatGPT, Claude, and Google AI Mode (BrightData, Oxylabs, Olostep) |
| **Compatible CLI** | Generates `elmo.yaml` + `.env` and runs `docker compose` |

## CLI Commands Reference

Once Yonaris is running, these commands help you manage it:

```bash
# View live logs
elmo compose logs -f

# View logs for a specific service
elmo compose logs -f web

# Check service status
elmo compose ps

# Stop all services
elmo compose down
```

## Why some names still say `elmo`

`@elmohq/cli`, the `elmo` command, `~/.elmo`, `elmo.yaml`, the `elmohq/elmo-*` Docker images, and `ELMO_ENCRYPTION_KEY` are retained compatibility identifiers. The product name and application UI are Yonaris. Do not rename these identifiers in an existing deployment without migrating its Compose project, volumes, database connection, and encrypted credentials.

New configurations also set `DISABLE_TELEMETRY=1` by default. The compatible CLI does not contain an upstream analytics key or newsletter destination.
