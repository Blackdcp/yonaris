This guide is for developers working with Yonaris — whether you're tuning a deployment, hitting the REST API from another system, or contributing to the product.

> Yonaris currently preserves upstream-compatible package names, the `elmo` CLI command, Docker image names, config paths, and `ELMO_*` encryption variables so existing deployments and data continue to work.

## Operating Your Deployment

- **[Configuration](/docs/developer-guide/configuration)** — environment variables and deployment modes.
- **[API Reference](/docs/developer-guide/api-reference)** — the REST API for managing brands, prompts, and snapshots programmatically.
- **[Telemetry](/docs/developer-guide/telemetry)** — how Yonaris telemetry is configured and disabled.
