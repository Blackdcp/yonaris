# Overseas formal run validation fixtures

The former `overseas-formal-readiness` and `overseas-formal-one-shot`
forced-command operations are permanently rejected by the LAS dispatcher and
policy parsers. This directory is not a production request queue. Do not add a
production policy line, restore either workflow call, or give candidate code
the runtime dotenv or Docker socket.

Any future host-side formal-run capability requires a new operation name,
stable fixed arguments, and a new exact protocol bound to the active immutable
release and five-digest receipt. Re-enabling either retired name is not
supported.
